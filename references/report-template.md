## 一、可直接嵌入的 Prompt 骨架（主体）

以下段落作为最终 Prompt 的主干，按人物实际特征替换「按人物条件判断」的内容，并可在各区块补充说明。

```
请基于用户上传的正面形象照片，生成一张横向 4:3 的高完成度「AI 发型美学升级报告 / Before & After Hairstyle Upgrade Report」。

Image A 是用户上传的本人形象照片，是本次生成的核心身份参考。请严格保留用户本人的脸部辨识度、五官结构、脸型比例、年龄感、皮肤真实质感、表情气质和原有穿搭，让人一眼能认出是同一个人。本次升级重点只放在发型设计、头发长度、刘海处理、层次结构、蓬松度、两侧体积、发尾质感和发色建议上。不要改变五官、不要瘦脸、不要磨皮美颜、不要换衣服、不要靠妆容提升效果。

把画面设计成一张融合「高端发型顾问提案板 + 杂志型视觉编排 + 多方案对比 + 轻度幽默避坑感」的个人发型升级报告。既要专业、清晰、有设计感，也要有一点“原来这些发型不适合我”的轻微趣味感，但不能恶搞、不能故意丑化人物、不能做成整蛊图。

【整体版式】横向 4:3 构图，背景以白色、米白、浅灰为主，少量浅橄榄绿、灰蓝、柔和红色作为功能性强调色。采用「左侧 Before 原始发型大图 + 右侧 After 主推发型大图 + 中下部 Best Options 推荐区 + 下方 Less Flattering 避雷区 + 底部 Hair Style Guide 执行指南」的结构。主次层级清晰，清爽高级、留白合理、信息丰富但不拥挤，不做整页均匀小卡片矩阵。

【标题区】顶部主标题：AI 发型美学升级报告；英文副标题：Before & After Hairstyle Upgrade Report；可加辅助小标签：HAIR RESET / STYLE PROPOSAL / BEST CUT FOR YOU / Personal Hairstyle Upgrade。

【中央主视觉】左侧 Before 原始发型大图：保持用户当前发型的真实状态，包括原始长度、自然发量、头发凌乱度、贴头皮感、刘海状态、发尾状态和整体精神感，不偷偷优化。右侧 After 主推发型大图：必须是同一个人、同样的脸与气质、同样的服装和相似光线构图，只升级发型；After 明显更适合这个人，更精神、更清爽、更修饰脸型、更协调、更有日常高级感，且真实可执行。

【After 主推发型优化方向】根据人物真实条件自动判断最适合的发型并在 After 主图中体现：1. 更合适的刘海或露额比例；2. 更自然的头顶蓬松度；3. 更合理的两侧体积控制；4. 更干净的发尾与层次；5. 更有秩序的发量视觉；6. 更适合肤色与气质的自然发色；7. 整体头面比例更协调、更有精神。

【专业注释】在 After 主图上加精致编号圆点、细线箭头和局部放大注释，标注 6 个关键点：
01 刘海 / Bangs：刘海方向、长度或露额比例如何修饰五官
02 头顶 / Crown Volume：头顶蓬松度如何提升精神感
03 两侧 / Side Balance：两侧体积如何修饰脸型宽度
04 层次 / Layers：层次处理如何减轻厚重感
05 发尾 / Hair Ends：发尾更干净利落、更有秩序
06 发色 / Hair Color：自然发色如何提升整体气质

【左侧信息栏：Key Features】在 Before 大图附近设简洁信息栏，图标 + 中英混排短标签，不长篇文字，按人物实际条件展示：Face Shape / 脸型、Hair Density / 发量、Hair Texture / 发质、Natural Wave / 自然弯曲度、Forehead Ratio / 额头比例、Current Length / 当前长度、Styling Difficulty / 打理难度。

【Best Options 推荐区】4 个推荐发型方案卡，绿色勾选标识，每张都是同一个人、只改发型，附简短名称和一句优势描述。方案彼此有差异但都在合理范围内，偏自然、真实、可执行（示例：Soft Layer Cut 轻盈自然修饰脸型；Korean Clean Style 清爽精神日常高级；Side Part Natural 增加轮廓感更显利落；Airy Texture Look 更有空气感减少沉闷）。让人感觉“这个也适合、那个也不错”。

【Less Flattering 避雷区】3 个不推荐发型方案，红色叉号标识，带轻微趣味反差感但不恶搞、不离谱、不故意变丑，仍在现实发型范围内（示例：过度贴头皮显脸宽显疲惫；过厚齐刘海压住五官显闷；过度油头显老气太刻意；过短或过尖锐太凶太硬不协调）。

【Hair Style Guide 底部执行指南】用较少文字呈现：1. Best Hair Length / 最佳发长建议；2. Trim Focus / 修剪重点（刘海、两侧、头顶、发尾、层次）；3. Styling Method / 日常打理方式（吹干、抓蓬、轻造型）；4. Maintenance Cycle / 建议维护周期；5. Best Hair Colors / 推荐发色（3—4 个自然色卡，如 Natural Black、Dark Brown、Ash Brown、Soft Cool Brown，偏自然低调，不高饱和漂染）。

【物理真实性】After 发型必须像真实可执行的真发：发际线与额头衔接处有自然过渡的细碎发，无生硬贴图感；有符合发型逻辑的自然分缝与发流方向；边缘有少量自然飞发；发丝有真实重力垂坠感与受光面，高光方向与原图主光方向一致，整体光照阴影和原图保持一致；发色可带发根深色渐变，避免单一平涂色与过度光泽塑料感；头发遮挡脸部的部分符合真实厚度与层次逻辑。

【文字风格】短标签、短标题、短描述为主，不大段说明。中文为主，英文作辅助标签。清晰可读、不乱码、不大量无意义英文。整体像专业发型顾问给出的“个人发型提案”，加轻度趣味化表达。

【视觉语气】专业顾问感 + 一点“避坑提醒”的趣味感：推荐区让人觉得“这些发型确实挺适合”，避雷区让人觉得“哈哈，这种真的不太行”，整体高级、干净、好看、有设计感，不低级恶搞。

【底部小字】本报告为 AI 发型美学视觉提案，仅供参考。实际发型建议请以专业发型师面诊为准。

【严格避免】不改变用户身份、不换脸、不改变五官、不磨皮美颜、不改变穿搭、不靠化妆或服装提升效果；不生成夸张发型、杀马特、二次元造型、舞台造型、过度油头、过度漂染；多个发型方案必须长得像同一个人；不照搬参考图排版；做成高完成度、专业又有点趣味感的个人发型美学升级报告，而非普通发型合集图。
```

## 二、发型分析维度（判断 After 与推荐卡描述用）

组装 Prompt 前，按以下维度分析照片与拟定发型，保证每个推荐/避雷方案都有具体细节而非笼统名称：

| 维度 | 要判断的内容 | 示例 |
|---|---|---|
| 分线 | 中分、偏分、无明显分线、刘海类型 | 偏分 + 侧分刘海 |
| 长度 | 到耳朵/下巴/锁骨/胸上/胸下/肩胛/腰 | 锁骨长度 |
| 卷度 | 直发、内扣、S 型波浪、大波浪、水波纹、羊毛卷、螺旋卷 | 自然 S 型大波浪 |
| 层次 | 齐发尾、低层次、高层次、脸周层次、发尾层次 | 脸周高层次 + 发尾碎层 |
| 发量与蓬松度 | 贴头皮、自然蓬松、空气感、丰厚 | 顶部自然蓬松、两侧收薄 |
| 脸周发丝 | 贴脸碎发、八字刘海、face-framing layers | 八字刘海修饰颧骨 |
| 发色 | 主色、冷暖调、明度、饱和度、反光色、雾感 | 冷调深棕、低饱和、雾面 |
| 质感 | 柔顺、毛流清晰、细碎飞发、沙龙光泽、雾面 | 毛流清晰、轻度飞发 |

判断依据（人物条件）：脸型轮廓、额头比例、发际线、五官量感、颈肩比例、发质条件、个人气质、日常打理成本。

## 三、发型命名库（推荐区/避雷区选词用）

**自然推荐向**（偏韩系/日系自然、可执行）：

- 韩系空气感中分鲍勃、韩系高层次 S 型大波浪、韩系女神水波纹长发
- 法式大波浪、法式慵懒锁骨发、日系轻盈碎发
- 八字刘海长卷发、侧分自然纹理短发、低层次柔和长发
- 干净利落短发、轻纹理上梳、自然短碎、中长内扣

**避雷向**（"确实不适合"的反差示例，仍在现实范围内）：

- 过度贴头皮油头、厚重齐刘海、超短贴耳寸头、过量锡纸烫、过度漂染浅金
- 描述方式：先给发型名，再附一句失败原因（显脸宽/显闷/显老气/太凶太硬）

## 四、按人物特征自动判断的内容（每次执行时替换）

组装 Prompt 前用 Read 分析照片，把以下占位内容替换为具体判断，保证报告言之有物：

| 区块 | 自动判断内容 | 示例 |
|---|---|---|
| Key Features 信息栏 | 脸型、发量、发质、自然弯曲度、额头比例、当前长度、打理难度 | 圆脸 / 发量偏多 / 粗硬自然直 / 额头中等 / 中长发 / 打理难度中 |
| After 方向 | 刘海或露额、蓬松度、两侧体积、层次、发尾、发色 | 斜刘海露额、顶部自然蓬松、两侧收薄、碎层次、发尾轻盈、深棕色 |
| Best Options 4 卡 | 4 个差异化的自然发型方案与一句话优势 | 从「发型命名库」中按人物脸型/发质选择或调整 |
| Less Flattering 3 卡 | 3 个“确实不适合”的反差方案 | 从「发型命名库」中选择与人物条件冲突的 3 个 |
| Hair Style Guide | 最佳发长、修剪重点、打理方式、维护周期、推荐发色 | 按 After 方案反向生成可执行建议 |

判断原则：所有推荐必须符合人物真实条件（脸型、发量、发质、年龄感），可执行、生活化；禁止给出与照片条件矛盾或夸张的推荐。

## 五、工具与交付参数

- 工具：`image_edit`，`image_reference_url_list` = [用户照片 URL]，Prompt = 上方骨架 + 按人物特征替换后的内容。
- 比例：横向 4:3（width=2048, height=1536 或按宿主工具上限）。
- 模型：按 `doubao-creative-design` 规则路由，用户未指定时用默认模型。
- 交付：生成 1 张 → 立即 `present_files` 独立交付，文件命名 `hairstyle-report-01.png` 等。
